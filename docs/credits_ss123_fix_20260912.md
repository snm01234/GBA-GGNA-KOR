# 엔딩 스탭롤 중복 표시 및 인명 한글화 (2026-09-12)

고정 ROM `SD Gundam GGeneration Advance (Korean).gba`에 반영했다.

## 원인과 수정

- 사용자가 제공한 ss1, ss2, ss3은 모두 엔딩 크레딧이다.
- 20260907 단일 문자열 재배치가 크레딧의 이중 NUL 목록 계약을 지키지 않았다. 문자열 끝의 NUL 외에 목록 종료 NUL이 필요하다. 정렬 여백이 없는 항목에서는 다음 문자열을 추가 줄로 읽었다.
- ss1의 목록 53, ss2의 목록 67, ss3의 목록 98에서 원래 한 줄인 직함 뒤에 다음 이름을 또 출력하는 현상을 ARM 코드로 재현했다. 수정 후 모두 한 줄만 출력한다.
- 목록 68(이벤트 스크립트), 83(세일즈), 93(선라이즈 협력) 등은 첫 줄만 재배치되어 후속 이름이 누락되었다. 원본 71개 목록, 83줄 전체를 다시 구성해 복원했다.
- 인명은 일본어 이름의 발음을 한글로 표기했다. 미해독 14줄과 기존 오독(亀尾, 片桐 등)도 크레딧 자료에 맞춰 정정했다. 긴 두 사람 이름 줄은 성·이름 사이 공백을 줄여 18칸 이내로 맞췄다.
- 모든 크레딧은 전용 빈 영역 `0x013D0000`에 배치했다. 원본 시나리오·렌더러 코드는 그대로이며, 71개 포인터와 새 문자열, 부족했던 한글 글꼴 2칸만 변경했다.
- 과거 단일 문자열 패치 도구는 크레딧을 건너뛰도록 수정해 같은 경로로 목록 구조가 손상되지 않게 했다.

## 검증과 재생 주의

- 71개 목록의 줄 수·순서·이중 NUL 경계를 원본과 비교했다.
- 실제 ROM의 ARM 함수 `0x080116C4`를 Unicorn에서 실행해 83줄의 포인터와 줄 간격(16픽셀)을 검증했다. ss1/ss2/ss3 관련 중복은 수정 전 2줄, 수정 후 1줄로 회귀 검증했다.
- 한글 토큰이 실제 ROM 글꼴 비트맵과 일치하는지 검사했다.
- `outputs/20260912_ss123_credits/all_credits_arm.png`는 ARM 실행 결과의 텍스트 레이어만 표시한 검사 도표다. `ss123_arm_redraw.png`도 명시적으로 지정한 좌표에서 텍스트를 다시 그린 진단 이미지이며, 전체 게임 실행 화면이 아니다.
- mGBA SDL의 GDB 연결이 열리지 않아 **전체 엔딩을 mGBA로 재생하는 검증은 하지 못했다.** ARM 검증은 캡처한 RAM과 즉시 DMA 모형을 사용한 제한된 출력 코드 실행이다.
- 원본 ss1·ss2·ss3와 배터리 세이브는 변경하지 않았다. 기존 상태를 불러오면 저장된 옛 VRAM이 먼저 표시된다. 수정 ROM을 새로 연 뒤 엔딩을 다시 시작하거나, 크레딧 화면이 전환된 후 확인해야 한다.
