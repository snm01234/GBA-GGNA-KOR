# ss1~ss4 누락 한글화 (2026-09-07)

갱신된 네 개 상태 저장 파일을 기준으로 원본 ROM, 현재 ROM, 통합 번역 데이터를 대조했다.

| 구분 | 확인 및 적용 내용 |
|---|---|
| ss1 방어 능력 설명 | 페이즈 시프트 장갑의 `威力700 軽減なし`를 `위력700 경감없음`으로 반영. 같은 방어 능력 테이블에서 확률·경감률 문구 16건을 함께 한글화 |
| ss2 지형 이름 | `砂漠` → `사막`. 같은 지형 테이블 44건을 판독·점검하고 누락 및 공장·평지·황무지·지하 동굴 등의 오역을 수정 |
| ss3 ID커맨드 | `この軟弱もの！！` → `이 나약한 녀석!!`. 같은 종류에서 번역이 보류된 이름/대사 13건을 원본 비트맵으로 판독해 반영 |
| ss3 미사용 선택지 | `IDコマンドを使用しない` → `ID커맨드를 사용하지 않음`. 누락된 레코드 GGA-TEXT-001BE795와 직접 포인터 0x0003AA88을 번역 데이터에 추가 |
| ss4 상태이상 배지 | 리소스 64 `足止` → `발묶기`, 리소스 65 `ID封印` → `ID봉인` |

## 누락 원인

- 방어 설명: `軽・減・率・%` 글리프 판독이 미완료 상태여서 숫자와 함께 나오는 설명이 pending으로 남아 있었다.
- 지형 이름: 내부 분류가 `series_title`로 되어 있어 지형 전용 점검에서 빠지기 쉬웠으며, 일부 글리프가 다른 한자로 잘못 대응되어 공장·평지 등의 번역도 잘못되어 있었다.
- ID커맨드: `軟`을 `野`로 읽는 등 기존 문자표와 실제 글리프가 불일치하여 13개 문구가 보류되어 있었다. 문장별 원본 비트맵 판독으로 확정했다. 문자표 전체에 무조건 적용하지 않고 확인된 레코드를 갱신했다.
- 미사용 선택지: 기존 `IDコマンドなし`와 별개인 직접 포인터 문자열이 통합 추출에서 빠져 있었다.
- 상태이상 배지: 기존 상승 계열 20~28과 별개인 64·65 리소스였다. 문자열 번역만으로 바뀌지 않는 그래픽 타일이다.

## 적용 및 검증

텍스트 74건을 점검·정리했고 기존과 바이트가 달라진 51건을 새 문자열 영역으로 연결했다. 현재 8×16 폰트에 실제로 그려진 한글을 역대조해 인코딩하고, 필요한 14개 글리프는 미사용 슬롯에 추가했다. 숫자와 기호도 원본 비트맵과 비교했다.

발묶기·ID봉인 배지는 일본어와 그림자를 제거한 배경을 만든 후 Galmuri 한글과 기존 색상 계열의 세로 그라데이션을 적용했다. 원래 리소스의 16개 전용 타일만 교체했으며, 압축 해제된 아틀라스 크기 519타일(16,608바이트)을 유지했다. 리소스 64·65 이외의 상태 화면 그래픽은 픽셀 단위로 동일함을 확인했다. ss4의 VRAM에 두 리소스의 원본 타일이 실제로 상주하는 것도 확인했다.

문자열 포인터, 토큰 종료, 출력 글리프, 압축 왕복, 수정 범위를 검증했다. ss4 미리보기는 갱신된 VRAM으로 재구성한 화면이며 에뮬레이터 재진입 시험은 아직 수행하지 않았다. 사용자 원본 ss1~ss4와 sav 파일은 수정하지 않았다.
