원인은 BG1 팀 카드 아틀라스의 안내창 전용 합성 타일이다. 평상시 카드와 달리 맵 13에는 기존 일본어 상성 글자의 상단 일부가 남았고, 맵 14에는 녹색 폴더 배지의 윗부분이 빠진 별도 타일이 있었다.

- 맵 13 상성 글자의 노출 부분을 정상 한글 타일에서 복원. 안내창의 하단 테두리·그림자에 가려지는 첫 세 행은 보존했다.
- 맵 13/14의 폴더 내부 상단을 정상 비활성 카드 맵 11/12에서 가져와 좌우 같은 모양으로 복원. 안내창 하단 테두리는 유지했다.
- 총 386타일 및 압축 리소스 크기를 유지. 동일한 빈 타일 323/48을 통합하여 필요한 합성 타일 슬롯을 확보했고, 해당 비행 지형 라벨은 시각적으로 동일함을 검증했다.
- 23개 맵을 모두 재해독하여 대상 합성 타일 외의 시각적 변경이 없음을 확인했다.

- 원본 savestate, 배터리 세이브, 번역 원장은 변경하지 않았다.
