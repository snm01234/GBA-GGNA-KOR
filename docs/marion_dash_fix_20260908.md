# 마리온 전투 대사 줄표 수정

갱신된 `SD Gundam GGeneration Advance (Korean).ss1`의 상태 데이터에는 컷인 컨테이너 `0x092A2028` 포인터가 있으며, 내장 화면에도 `값값난폭한…`이 보인다. 해당 대사는 컷인 테이블 `0x00228604`에서 참조한다.

번역문은 `「――난폭한 사람은싫어……」`이다. 줄표 `―`의 원래 토큰 `E005`는 12×12 슬롯 `0x00E5`를 참조하지만, 현재 ROM에서 이 칸은 Galmuri의 `값` 비트맵과 일치한다. 번역 오타가 아니라 원래 문장부호와 한글의 폰트 슬롯 충돌이다.

원본 줄표 비트맵을 미사용 슬롯 `0x07B9`에 복사하고, 컷인 대사 `0x092A202E`와 대응 맵 이벤트 대사 `0x09094352`의 줄표 토큰만 `E6D9`로 변경했다. 기존 `값` 슬롯은 유지했다. 두 인코더에 같은 매핑을 적용하고, 통합 빌더에서도 새 슬롯 예약과 원본 줄표 복사가 이루어지도록 했다.

검증: 갱신된 상태의 컷인 포인터 확인, 수정 전 대사 바이트 전체 일치, 두 인코더 결과 일치, 새 슬롯과 원본 줄표 비트맵 일치, 기존 `값` 비트맵 보존, 허용 범위 외 ROM 변경 없음, 원본 맵 스크립트 뱅크 보존. 총 24바이트 변경. 실행 중 에뮬레이터 재현은 하지 않았으며 `outputs/20260908_ggen_advance_marion_dash/glyph_before_after.png`는 ROM 비트맵으로 만든 정적 비교 이미지다.

기본 한글 ROM에 반영했으며 이전 ROM은 main_tip/backups에 보관했다. SAV와 SS1은 변경하지 않았다. 대사가 이미 그려진 순간의 상태를 불러오면 저장된 화면 타일이 남을 수 있으므로, 수정된 ROM을 다시 열고 해당 대사가 새로 표시되는 시점에서 확인한다.
