# 팀 카드 배지 오역 점검

> **수정 적용 (2026-09-07):** 사용자 요청에 따라 일반·선택 상태 모두 `격납 → 이동`으로 수정했다. 제작 스크립트의 원문 매핑도 `移動 / 이동`으로 바로잡았다. 아래 내용은 수정 전 진단 기록이다. [수정 명세](../outputs/20260907_team_move_button_fix/manifest.json) · [수정 전후](../outputs/20260907_team_move_button_fix/normal_focus_before_after.png)

갱신된 ss1의 오른쪽 위 ‘격납’ 버튼은 원본 ROM에서 **移動(이동)**이다. 일반 상태와 선택 상태 모두 같은 오역이 있다.

## 원인

`tools/build_ggen_advance_team_card_ui_ko_20260903.py`의 `LABELS`에서 `storage_normal`과 `storage_focus`를 `jp: 格納`, `ko: 격납`으로 잘못 등록했다. 원본 글자 판독이 잘못된 상태로 고정 번역 이미지를 제작한 것이다. 기존 검증은 타일 위치·압축·배경 보존을 확인했지만 이 두 항목의 일본어 의미 오류를 잡지 못했다.

원본 아틀라스는 0x000D87F0이며 로더 포인터는 0x000DAB70이다. ss1의 BG2 타일 좌표 (26, 2)에서 보이는 버튼은 소스 타일 330, 331, 332, 333, 335, 336, 337, 338, 340, 341, 342, 343에 정확히 대응한다. 현재 VRAM과 번역 아틀라스 바이트도 일치한다. 따라서 타일 로딩 오류나 문자열 폰트 오류가 아니다.

같은 화면의 아래쪽 카드에 있는 ‘이동’은 별도 타일(43~46, 49~52)이며 올바르게 번역되어 있다. 같은 원문의 서로 다른 그래픽 리소스를 불일치하게 번역했다.

이번 작업은 진단이며 ROM·번역 아틀라스는 변경하지 않았다. 일반 상태(0x000DAA90)와 선택 상태(0x000DAAC8) 모두 수정해야 하며, 재발 방지를 위해 제작 스크립트의 원문 매핑도 함께 바로잡아야 한다.
