# 입수 아이템 그래픽 수정

갱신된 SS1의 정산 화면에서 `入手アイテム`이 출력되는 원인은 별도 오버레이 타일맵에 대한 한글화 누락이었다. 기존 작업은 기본 정산 맵 `0xE7894`에만 적용되었고, 아이템 표시용 맵 `0xE7D48`, `0xE7EB4`는 일본어 타일을 유지했다.

SS1의 BG1 타일맵과 `0xE7D48`의 타일 번호를 대조했고, VRAM의 아틀라스 전체가 현재 ROM의 `0x1F94000` 압축 리소스와 일치함을 확인했다. 두 맵의 제목 영역을 `입수아이템`으로 교체했다. 기존 Galmuri11 글꼴, 녹색 글자 및 외곽선, 주황색 배경 스타일을 사용했다.

변경 대상에만 속한 타일 슬롯을 재사용하여 아틀라스 크기를 유지했다. 세 정산 맵의 모든 비대상 셀에 대해 타일맵 값과 픽셀 바이트 보존을 검증했다. 압축 해제 왕복 검증 및 허용 범위 외 ROM 변경 없음도 통과했다.

기본 한글 ROM에 반영하고 이전 ROM을 main_tip/backups에 백업했다. SAV와 SS1은 수정하지 않았다. `outputs/20260908_ggen_advance_obtained_item/ss1_after_static.png`는 상태 데이터와 수정된 ROM으로 재구성한 정적 미리보기이며, 에뮬레이터 실행 캡처는 아니다. 저장 상태에 기존 VRAM 화면이 포함되어 있으므로 수정된 ROM을 다시 열고 정산 화면에 새로 진입하여 확인한다.
