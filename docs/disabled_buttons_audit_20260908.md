# 비활성 버튼 추가 점검 및 로드 수정

확인된 비활성 버튼 계열을 현재 기본 ROM에서 재점검했다. 타이틀 메뉴 리소스 `0x08CCFE40`의 비활성 로드 애니메이션 20만 원본 일본어 비트맵과 동일했다. 해당 애니메이션의 전용 타일 181~192를 `로드`로 수정했다. 기존 비활성 이어하기/부록/컨티뉴와 동일하게 Galmuri11, 글자색 4, 외곽선 1, 복원한 회색 배경을 사용했다.

타이틀 비활성 18(이어하기), 19(부록), 20(로드), 21(컨티뉴)의 한글 잉크 및 외곽선을 기대 비트맵과 대조했다. 다른 25개 타이틀 애니메이션의 픽셀은 모두 보존했다. 공유 타일, 팔레트, 애니메이션 레코드 및 다른 ROM 영역도 유지했다.

탑재/내리기/이동/변형은 원본 C3F130 패키지가 아니라 실제 소비자 `0x66CE8`이 참조하는 한글 복제 패키지 `0x092F0000`을 검사했다. 각 비활성 애니메이션 8~11이 일반 상태 0~3과 동일한 한글 타일 집합을 사용함을 확인했다. 일부는 빈 타일 순서만 다르므로 타일 다중집합을 비교했다. 산개/유지는 기존에 비활성 상태가 일반 그래픽을 공유한다고 확인된 직접 리소스 `0xA9C264`, `0xA9C43C`의 한글화를 재확인했다. 이들은 추가 변경하지 않았다.

이번 점검은 확인된 타이틀·탑재 메뉴·대형 메뉴의 비활성 계열을 대상으로 한다. 게임 전체의 모든 비활성 상태를 에뮬레이터에서 순회했다는 의미는 아니다. ROM 비트맵 및 정적 미리보기 검증을 수행했고 실행 검증은 하지 않았다.

기본 한글 ROM에 반영하고 이전 ROM을 main_tip/backups에 백업했다. 사용자 저장 파일은 변경하지 않았다.
