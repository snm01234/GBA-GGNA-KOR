# ss1·ss2 일본어 및 잘못된 글꼴 출력 수정

## 화면별 결과

| 화면 | 원인 | 적용 결과 |
|---|---|---|
| ss1 브라이트의 발포 대사 | 무기명 `主砲`의 대사용 항목이 생산 화면용 8×16 문자열을 공유함. 12×12 대사 글꼴에서는 같은 토큰이 `際大`처럼 보이는 다른 한자로 출력됨 | `주포!` / `쏴라!` |
| ss2 보급 화면 | `破損中`의 번역문은 등록되어 있으나 실제 출력 포인터에는 일본어 문자열이 남아 있음 | 오른쪽 끝 24픽셀에 맞춰 `파손중` |

두 state의 ROM CRC는 검사 당시 기본 ROM과 일치했다. 따라서 이번 두 화면의 문제는 이전 ROM을 실행한 데서 생긴 현상이 아니다.

## 같은 종류 전체 검사

전투 대사에 삽입되는 무기명 **165종, 포인터 1,468개**를 검사했다. 한글뿐 아니라 영문·숫자·공백도 현재 ROM의 실제 12×12 글꼴과 대조했다.

- **35종, 포인터 130개 수정.** 첫 한글 중심 검사에서 25종을 발견했고, 영문·숫자를 포함한 검사에서 10종을 추가했다.
- 기존에 올바르게 표시되던 130종의 출력 포인터는 보존했다.
- 생산·기체 상세 화면에서 사용하는 8×16 무기명 포인터는 변경하지 않았다.
- 대사용 무기명은 8×16 항목의 단순 별칭에서 분리하여 독립적인 12×12 번역 항목으로 등록했다. 재빌드 도구도 해당 항목을 12×12로 처리하도록 수정했다.
- 필요한 12×12 글자 `딩`, `믹`, `샷`, `펩`, `핸`은 빈 글꼴 슬롯에 추가했다.

수정 대상에는 주포, 바위던지기, 저격, 흉부미사일, 핸드건, 샷건, 아토믹 바주카, 폴딩 바주카, 샤이닝 샷, 대구경 빔 캐논, 전탄발사, 석파천경권, 패왕전영탄, CIWS 등이 포함된다. 전체 항목과 변경 주소는 아래 manifest에 기록했다.

## 검증 및 산출물

- 모든 대사용 포인터의 출력 글리프 및 수정 대상의 토큰·종료 문자 확인.
- 기존 생산용 포인터, 정상 대사용 포인터, 맵 이벤트 명령 보존 확인.
- 독립 검증 스크립트 통과. 기존 통합 파이프라인 회귀 검사 6건 통과.
- 회귀 검사는 Windows 임시 디렉터리 ACL 문제를 피하도록 작업 폴더 안에 일반 권한의 테스트 디렉터리를 생성하여 실행했다. 테스트 검증 내용은 변경하지 않았다.
- 미리보기는 캡처 이미지의 해당 글자 영역을 후보 ROM 글꼴로 재구성한 결과다. 에뮬레이터 재진입 실행 검증은 수행하지 않았다.
