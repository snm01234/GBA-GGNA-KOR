# 이동 비활성 버튼 한글화

갱신된 SS2에서 BG0의 화면 (32,56) 버튼은 액션 메뉴 리소스 42를 사용한다. 현재 리소스 테이블은 `0x127C000`, 압축 아틀라스는 `0x1278000`이다. 일반/선택 상태의 리소스 18/30은 한글이지만, 비활성 리소스 42의 원본 일본어 타일 223~230은 남아 있었다. SS2의 VRAM 타일 959~966이 이 소스 8개와 모두 일치함을 확인했다.

기존 한글 일반 버튼의 `이동` 외곽선 마스크를 재사용했다. 비활성 ID 버튼과 동일하게 배경/글자색 인덱스 3, 외곽선 2, 바깥 테두리 11을 사용하고 원래 둥근 테두리를 보존했다.

대상 8개 타일이 다른 리소스와 공유되지 않음을 검증한 뒤 해당 타일만 교체했다. 아틀라스는 239타일/7648바이트로 유지했고, 압축 왕복 검사와 모든 비대상 액션 리소스의 픽셀 일치 검사를 통과했다. 기본 한글 ROM에 반영하고 이전 ROM을 main_tip/backups에 백업했다. SAV와 SS2는 변경하지 않았다.

`outputs/20260908_ggen_advance_disabled_move/ss2_after_static.png`는 수정 ROM의 타일을 SS2 그래픽 메모리에 적용해 재구성한 정적 미리보기다. 에뮬레이터 실행 검증은 하지 않았다. 기존 상태에는 일본어 화면 타일이 저장되어 있으므로 수정 ROM을 다시 열고 메뉴를 다시 표시하여 확인한다.
