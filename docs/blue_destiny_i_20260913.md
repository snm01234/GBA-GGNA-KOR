# 블루 데스티니 I 이름 통일

메인 TIP `37e1ef1b66f34ebf27ede05c1cc26122a884345073037a3709bfa6e4a6503c26` 기준으로 `BD I` 이름 5개 레코드를 `블루 데스티니 I`로 변경했다.

포인터 위치는 `0x18EFAC`, `0x195520`, `0x19CE10`, `0x1AFE2C`, `0x1AFE50`이다. 첫 세 경로의 기존 선행 아이콘 슬롯 `<07FB>`, `<07F8>`, `<07FC>`는 각각 보존했다. 새 문자열은 비어 있는 `0x013D8000`부터 정렬 배치했다. 기존 폰트는 변경하지 않았다.

각 포인터의 기존 문자열과 변경 후 디코딩을 대조했고, 사용한 한글 글리프의 실제 ROM 바이트를 폰트와 비교했다. 이름은 8×16 폰트로 72픽셀, 선행 아이콘 포함 시 80픽셀이다. 허용된 포인터와 신규 문자열 영역 밖의 ROM 바이트는 보존했다.

현재 제공된 ss1은 상황 메뉴, ss2는 편성 화면으로 BD I 이름이 노출되지 않는다. 따라서 두 savestate에서 해당 이름의 실시간 표시를 검증한 것은 아니다. `outputs/20260913_blue_destiny/name_after.png`는 실제 ROM 폰트로 그린 이름이며, 사용자 savestate는 변경하지 않았다.
