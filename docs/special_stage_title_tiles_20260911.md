# 특수 스테이지 제목 타일 한글화

제공된 `SD Gundam GGeneration Advance (Korean).ss1`은 엑스트라 세션 4의 `裁かれし者` 화면이다. 기존 25개 BG 제목 테이블(0x08D58B40)과 별개인 OBJ 리소스 0x08D51674에 다음 세 화면이 들어 있다. 코드 참조는 파일 오프셋 0x5ED14이며 0x0805EC64 로더가 애니메이션을 선택한다.

| 애니메이션 | 세션 | 원문 | 번역 |
|---|---|---|---|
| 0 | 엑스트라 세션 4 | 裁かれし者 | 심판받은 자 |
| 1 | 16th 세션 | 光る宇宙 | 빛나는 우주 |
| 2 | 라스트 세션 | 妄執、果てる時 | 망집이 끝날 때 |

Galmuri11 Regular의 원래 픽셀을 사용했다. 일본어 세션 표기도 번역했으며 영어 부제와 번호의 픽셀 모양은 보존했다. 엑스트라 세션은 번호를 포함해 가운데 정렬했다. 공유 타일을 그대로 덮어쓰지 않고 3개 애니메이션의 타일을 재구성하여 중복 제거하고 각 소스 타일 참조를 갱신했다. 266개 타일 공간 안에서 220개를 사용하므로 리소스 재배치나 코드 변경은 없다.

제공 상태의 OBJ 타일 116개가 원본 리소스와 바이트 단위로 일치함을 확인했다. 세 애니메이션 모두 타일 재구성 후 픽셀이 의도한 화면과 일치하며, 영어 부제 및 숫자 보존과 허용된 수정 범위를 검증했다. 별도 숨김 mGBA의 로컬 GDB 접속은 두 번 모두 시간 초과되어 실제 구동 검증은 완료하지 못했다. 미리보기는 타일/저장 상태 메모리 재구성이며 에뮬레이터 캡처가 아니다.

루트 한글 ROM은 기존 파일을 백업한 뒤 프로젝트의 승격 스크립트로 갱신했다. 원본 ss1 및 일반 세이브는 변경하지 않았다. 기존 상태에는 옛 VRAM이 저장되어 있으므로 상태를 불러온 직후에는 일본어 화면이 남을 수 있으며, 수정 ROM에서 해당 스테이지 제목을 새로 로드해야 한다.
